    50Ω 기준: 표시 진폭은 50Ω 부하에 걸리는 값이라, 개방(High-Z) 회로에서는 실제로 약 2배가 나와요.

    선택한 부품

    새 부품 설정

    점퍼선 색 (계기 단자에서 시작하면 단자 색을 따라감)

    부품 목록

    예시: 전원 CH1(5V) → R1 1kΩ → R2 2.2kΩ 전압 분배. CH1 −는 GND에 접지했고, 멀티미터와 스코프 CH1이 R1·R2 사이 노드를 재고 있어요. ‘전체 초기화’로 지울 수 있어요.

      조작법

      • 리드선: ‘점퍼선·리드선’ 도구로 계기 단자(동그란 잭)와 보드 구멍을 이어요. 단자 하나에 여러 가닥을 꽂을 수 있어요.
      • 전원: 손잡이를 위아래로 끌거나 마우스 휠로 전압·전류 제한을 바꾸고 OUTPUT으로 켜고 끕니다.
      • 접지: 전원 GND(초록) 단자와 스코프 접지클립은 기기 안에서 대지에 연결돼 있어요. CH1 −를 GND에 이으면 회로가 접지됩니다.
      • 신호발생기: 파형(Sine/Squ/Tri)을 고르고 FREQ·AMPL·OFST 버튼으로 바꿀 값을 정한 뒤 손잡이로 조절해요. 검정 클립은 접지예요.
      • 스코프: ▲▼로 V/div, ◀▶로 시간축, DC/AC로 입력 결합을 바꾸고, Auto Scale로 한 번에 맞춰요.
      • 멀티미터: 전압·저항은 VΩ–COM, 전류는 mA(또는 10A)–COM에 꽂고 회로에 직렬로 넣어요.
      • 저항·점퍼선: 시작 구멍 클릭 → 끝 구멍 클릭. 끌어서 놓아도 됩니다.
      • 이동·삭제: 몸통을 끌면 통째로, 끝 동그라미를 끌면 한쪽만 이동. Delete로 삭제, Esc는 취소.
      • 배치와 계기 설정은 이 브라우저에 자동 저장됩니다.
